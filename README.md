# 🎭 Catfish Roulette (Instagram Direct Messages Clone)

A real-time, anonymous chat roulette web application (Omegle/OmeTV mechanics) disguised with a pixel-perfect **Instagram Direct Messages dark mode UI**.

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Firebase (Realtime Database & Presence System)**.

---

## ⚡ Key Highlights & Features

1. **The Identity Selector (Landing Screen)**:
   - **Normal Mode**: Chat as an autogenerated anonymous stranger (`@user_XXXX`) with default Instagram silhouette avatar.
   - **Catfish Mode**: Roleplay as anyone! Customize fake Display Name, Instagram Handle (`@handle`), Avatar URL, Bio, and Verified Blue Tick (`✓`). Includes one-click presets (Bella Thorne, Julian Vance, Elena Rostova, etc.) and a live DM profile preview.

2. **The Matchmaking Screen (Loading Radar)**:
   - Instagram Stories gradient ring pulsing animation (`#f09433` via `#dc2743` to `#bc1888`) with radiating sonar ripples.
   - Dynamic real-time status feedback: *"Scanning for live connections..."* ➔ *"Pairing with @handle..."*.
   - Instant cancel button to exit queue.

3. **Flawless Instagram DM Clone (Dark Mode)**:
   - **Header**: Peer avatar, live active indicator (`Active now`), verified badge, fake phone/video call buttons, details drawer.
   - **Crucial "Next / Skip" Button**: Prominently placed in the top right header (`[ Next ⏭️ ]`) and bottom input bar. Single click or `Esc` shortcut instantly ends the chat, alerts the peer, clears state, and re-triggers matchmaking.
   - **Message Feed**: Outgoing gradient bubbles (`#7638fa` to `#d300c5`), incoming dark bubbles (`#262626`), double-tap heart reactions, typing indicator (`...`), and "Seen" receipts.
   - **Input Bar**: Pill container with camera button, heart sender, voice/image dummies, and dynamic blue "Send" button.

4. **Robust Matchmaking & Presence Engine**:
   - Atomic transactions prevent race conditions when pairing users.
   - Native Firebase `onDisconnect()` hooks guarantee that if a user closes their tab or browser, they are instantly purged from the queue or their active room is marked as disconnected.
   - Built-in zero-config multi-tab local mesh simulator for local offline testing even before configuring Firebase credentials.

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Configure Firebase (Optional for multi-tab localhost test)
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

Fill in your Firebase credentials from your Firebase Console project:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSy...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-app.firebaseapp.com
NEXT_PUBLIC_FIREBASE_DATABASE_URL=https://your-app-default-rtdb.firebaseio.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your-app
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-app.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789
NEXT_PUBLIC_FIREBASE_APP_ID=1:123456789:web:abcdef
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Tip**: Open two tabs or an incognito window to watch the instant pairing and roulette mechanics in real time!
